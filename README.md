# ACAUS · Doceria Artesanal

Projeto desenvolvido por **ACAUS**.

Catálogo de produtos de confeitaria artesanal: brigadeiros gourmet, brownies, bolos de pote e kits feitos à mão.

## Desenvolvimento

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
